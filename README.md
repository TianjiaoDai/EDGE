# EDGE
This repository contains R scripts for analyzing soil microbial community responses to extreme drought across a continental-scale precipitation gradient, supporting the manuscript: "Extreme drought favors soil microbial generalists across grasslands".

Script Descriptions
1. Diversity Analysis: LMM.R
This script performs Linear Mixed-effects Models (LMM) to evaluate the impact of drought on microbial alpha diversity.

2. Niche Analysis Workflow: niche.R
This workflow utilizes partial Canonical Correspondence Analysis (pCCA) to isolate moisture-independent niche axes and quantifies both taxon-level and community-weighted mean (CWM) niche breadths and optima.
